# Attribution & Upstream Suite

Magic Studio builds on community-maintained open-source libraries and interoperates with the ArtCraft creative suite:

- **[`storytold/craft-libs`](https://github.com/storytold/craft-libs)** (`MIT OR Apache-2.0`) — shared document paths, atomic file I/O, audio analysis, `.ecproj`/`.pcraft`/`.vectorcraft` formats, settings, dialogs, keymaps, and update checks.
- **[`storytold/craft-ai-integrations`](https://github.com/storytold/craft-ai-integrations)** (`MIT OR Apache-2.0`) — provider authentication and model routing.
- **[`storytold/craft-common-actions`](https://github.com/storytold/craft-common-actions)** & **[`storytold/craft-contrib`](https://github.com/storytold/craft-contrib)** — CI/release workflows and workspace house rules.
- **External ArtCraft Applications** (invoked as external processes via `<craft>-cli` and `--control`): [`FilmCraft`](https://github.com/storytold/filmcraft), [`EffectCraft`](https://github.com/storytold/effectcraft), [`DesignCraft`](https://github.com/storytold/designcraft), [`PhotoCraft`](https://github.com/storytold/photocraft), [`VectorCraft`](https://github.com/storytold/vectorcraft), and headless [`AniCraft`](https://github.com/storytold/AniCraft).
