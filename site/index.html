Built on storytold/craft-libs · Coordinates DesignCraft, PhotoCraft, VectorCraft, EffectCraft & FilmCraft

Where a recorded song becomes a living storybook film.

Magic Studio is a lightweight desktop shell, CLI (magic-cli), and MCP server (magic-cli mcp) that turns one song recording into a reference-locked DesignCraft storyboard, expressive 11-pin EffectCraft puppet lip-sync, kinetic teaching lyrics, and a clean V1–V4 FilmCraft timeline.

magic-cli · live --control & MCP workflow 
# 1. Watch Magic Studio live while your MCP client drives it
magic --control 9875 &
claude mcp add magic-app -- magic-cli mcp --connect 127.0.0.1:9875

# 2. Start a song project (transcribes timing-reference.json + FilmCraft A1 + DesignCraft board)
magic-cli new --root ~/Videos/Magic --name "Rendered Yesterday" --audio song.wav --wizard

# 3. Isolate character in PhotoCraft, rig 11-pin face in EffectCraft & lip-sync visemes
magic-cli --project "Rendered Yesterday.magic" --save exec character.cut character=fox remove_background=true rig=true
magic-cli --project "Rendered Yesterday.magic" --save exec character.puppet.rig_face character=fox
magic-cli --project "Rendered Yesterday.magic" --save exec character.puppet.lipsync character=fox

Single-Responsibility Track Architecture

Every Craft app does what it does best.

Magic Studio never reimplements raster matting, vector tracing, puppet meshes, or NLE rendering in-process. Each domain owns its native ArtCraft file and publishes to an isolated FilmCraft track.

Lightweight Shell · Real CLI Delegation

Built to watch live with --control.

Start magic --control 9875 and attach magic-cli mcp --connect 127.0.0.1:9875. Every tool call updates the pure-Rust egui workspace in real time while confining file access with --automation-read-root and --automation-write-root.

  • Native egui 0.37 + craft-ui + craft-menu control system enforcing crisp SVG icons and single-word buttons with zero baseline drift.
  • Loopback 64-hex token auth + immediate TCP stream close on HTTP/browser line-smuggling attempts.
  • Direct ui.effectcraft and ui.filmcraft bridges for frame-accurate timeline and compositor control (with early-alpha AniCraft locked to headless CLI only).
