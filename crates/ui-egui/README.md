# `magic-ui-egui` (`crates/ui-egui`, Layer 6)

> **Last Reviewed & Updated:** 2026-11-12T16:59:00-05:00 · **Reviewed by:** Jesse A. Naiman

Workstation user interface for Magic Studio built on [`emilk/egui`](https://github.com/emilk/egui) (`storytold/egui`), [`craft_ui::docking`](../../docs/craft-reference/craft-libs/docs/ui-docking.md), [`craft-font-manager`](../../docs/craft-reference/craft-libs/crates/craft-font-manager/README.md), [`craft-font-store`](../../docs/craft-reference/craft-libs/crates/craft-font-store/README.md), and [`storytold/font-preview-service`](../../docs/craft-reference/font-preview-service/README.md).

> **Shared Docking Architecture:** Every workspace panel, tab group, collapsible dock column, and floating window is driven directly by **`craft_ui::docking`** (`Workspace<PanelId>`, `Layout<PanelId>`, `DockArea`, `DockContent<PanelId>`, `DockStyle::from_ui`, `DockCommand<PanelId>`, `FloatSpace`, and native desktop floating windows). Every `.rs` file is strictly `< 900` lines.
