# `magic-engine` (`crates/engine`, Layer 5)

> **Last Reviewed & Updated:** 2026-11-12T16:59:00-05:00 · **Reviewed by:** Jesse A. Naiman

Headless project coordinator, command registry (`Session::execute`), `storyboard.designcraft` document model, `craft-zip` folder archiver, and host Craft application bridge for Magic Studio. Every button in [`crates/ui-egui`](../ui-egui/README.md), every subcommand in [`apps/magic-cli`](../../apps/magic-cli/README.md), and every tool call in [`crates/mcp`](../mcp/README.md) dispatches through `magic-engine`.
