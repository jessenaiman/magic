# Code of Conduct

Magic Studio adopts the [Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), aligned with [`storytold/craft-contrib`](https://github.com/storytold/craft-contrib).

All contributors and maintainers are expected to foster an open, welcoming, constructive, and harassment-free community. Report unacceptable behavior privately to the repository maintainers via [SECURITY.md](SECURITY.md).
