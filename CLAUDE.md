# CLAUDE.md

Read [`AGENTS.md`](AGENTS.md) and [`docs/mcp.md`](docs/mcp.md) first.

- Register MCP with `claude mcp add magic -- magic-cli mcp` (or `claude mcp add magic-app -- magic-cli mcp --connect 127.0.0.1:9876` when watching `magic --control 9876` live).
- Delegate media, compositing, cutout, vector, and layout work to installed ArtCraft tools (`FilmCraft`, `EffectCraft`, `DesignCraft`, `PhotoCraft`, `VectorCraft`, and headless-only `anicraft-cli`).
- Never maintain custom animation how-to markdown dumps in the repo; reference official ArtCraft docs directly.
